# כנף · מלווה טיסה

אפליקציית ווב לטלפון: מחפשים טיסה לפי מספר ותאריך ומקבלים סטטוס, זמנים, טרמינל, שער, המטוס ומיקום חי.
הנתונים מגיעים מ-Aviationstack דרך שרת קטן (`app/api/flight/route.js`) שמחזיק את המפתח, כך שהדפדפן לא רואה אותו.

## הרצה במחשב

1. מתקינים Node.js בגרסה 18 ומעלה.
2. מעתיקים את `.env.example` לקובץ חדש בשם `.env.local` ומדביקים בו את המפתח שלך.
3. מריצים:
   ```
   npm install
   npm run dev
   ```
4. פותחים את http://localhost:3000

## העלאה לאינטרנט ב-Vercel (חינם)

**דרך GitHub:**
1. מעלים את התיקייה ל-repository חדש ב-GitHub. הקובץ `.env.local` לא יעלה, כי הוא ב-`.gitignore`.
2. ב-vercel.com לוחצים על **Add New** ואז על **Project**, ובוחרים את ה-repository.
3. תחת **Environment Variables** מוסיפים את `AVIATIONSTACK_KEY` עם המפתח שלך.
4. לוחצים על **Deploy**. בסוף מקבלים קישור שעובד מכל טלפון.

**בלי GitHub:** מתוך התיקייה מריצים `npx vercel`, ואחר כך מוסיפים את המשתנה `AVIATIONSTACK_KEY` בהגדרות הפרויקט ב-Vercel.

## חשוב לדעת

- **מכסה:** במסלול החינמי של Aviationstack יש 100 בקשות בחודש. השרת שומר כל טיסה במטמון ל-5 דקות כדי לחסוך בקשות.
- **אילו טיסות נמצאות:** במסלול החינמי מופיעות רק טיסות מהימים האחרונים והקרובים. אם התאריך לא נמצא, האפליקציה מציגה את התאריכים הזמינים.
- **שעות:** Aviationstack מחזיר שעות מקומיות של כל שדה תעופה, אבל מסמן אותן כ-UTC. הקובץ `lib/time.js` מתקן את זה.
- **הזמן שנותר:** מחושב לפי שעת הנחיתה הצפויה, ומתעדכן במסך כל 30 שניות בלי בקשות נוספות.
